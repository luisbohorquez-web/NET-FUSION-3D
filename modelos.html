Cómo usar el visor
  • Un dedo (o clic) gira el modelo. Pellizca o usa la rueda para acercar. Dos dedos (o clic derecho) lo desplazan.
  • “Ver con cámara” pone el modelo sobre la imagen de tu cámara trasera. Pide permiso y solo funciona si la página está en https (por ejemplo, GitHub Pages). Con “Escala” lo ajustas al tamaño real que quieras comparar.
  • “Foto” guarda lo que ves, con o sin cámara.
  • “Importar modelo” acepta .glb (recomendado) o .gltf de un solo archivo. También puedes arrastrar el archivo sobre el visor. El modelo se procesa en tu dispositivo y no se sube a ningún servidor.
